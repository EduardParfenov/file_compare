Создай скелет (scaffold) проекта веб-приложения для сравнения двух версий
документов. На этом шаге НУЖНА ТОЛЬКО СТРУКТУРА И ИНФРАСТРУКТУРА — бизнес-логику
не реализовывать, она будет добавляться отдельными change-предложениями через
OpenSpec.

## СТЕК

- Python 3.11, Flask (фабрика приложения create_app), python-dotenv, LangChain (пакет langchain-openai).
- Виртуальное окружение: python -m venv .venv
- Frontend: чистые HTML/CSS/JS (vanilla), без сборщиков и фреймворков.
- Тесты: pytest.
- Конфигурация только через переменные окружения, все пути относительные
  (архитектура должна быть готова к упаковке в Docker позже).

## ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ (.env.example)

FLASK_APP, FLASK_DEBUG, SECRET_KEY,
LLM_BASE_URL=http://172.16.48.122:8002/v1, LLM_API_KEY, LLM_MODEL,
UPLOAD_DIR=./uploads, MAX_CONTENT_LENGTH, ALLOWED_EXTENSIONS=.docx,.xlsx

Реальный .env не коммитить.

## КОНФИГУРАЦИЯ

config.py читает переменные окружения и приводит типы:
- MAX_CONTENT_LENGTH → int
- ALLOWED_EXTENSIONS → список строк

create_app создаёт каталог UPLOAD_DIR, если он не существует.

## ЗАГЛУШКИ

Все модули в services/ создать с докстрингами и корректными сигнатурами функций,
тело — raise NotImplementedError. Это точки расширения для будущих change'ов.

POST /api/compare возвращает 501 и JSON {"error": "not implemented"}.

index.html содержит только каркас: две зоны загрузки, кнопка "Начать сравнение"
(disabled), контейнер под статус и под side-by-side панели. Обработчиков нет.

В style.css задать только CSS-переменные палитры (зелёный акцент для кнопок,
жёлтый для рамок, оттенки серого для текста и фонов) и reset.

## КРИТЕРИИ ПРИЁМКИ

- python -m venv .venv && pip install -r requirements.txt -r requirements-dev.txt
  проходит без ошибок.
- flask run поднимает сервер, GET / отдаёт страницу-каркас (200).
- GET /health возвращает 200 и {"status": "ok"}.
- POST /api/compare возвращает 501 и {"error": "not implemented"}.
- pytest проходит: тест на создание приложения через фабрику, тест /health,
  тесты маршрутов.
- README описывает установку, запуск и все переменные окружения.

## ЧЕГО НЕ ДЕЛАТЬ

Не реализовывать парсинг .docx/.xlsx, поиск различий, вызовы LLM, drag-and-drop,
спиннер, синхронный скролл и подсветку diff. Не писать Dockerfile.
Не добавлять зависимости сверх перечисленных.

## ПОСЛЕ СКАФФОЛДИНГА

- Выполни git init и сделай первый коммит скелета.
- Инициализируй OpenSpec в корне репозитория (openspec init) и заполни
  openspec/project.md: стек, структура каталогов, конвенции (TDD через pytest,
  моки для LLM в тестах, конфигурация через окружение, требования change'ов
  описываются на русском в стилистике BDD/Gherkin).
