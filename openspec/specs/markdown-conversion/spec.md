# markdown-conversion Specification

## Purpose

Конвертация загруженных документов в единое Markdown-представление, чтобы
дальнейшее сравнение не зависело от исходного формата файлов.

## Requirements

### Requirement: Конвертация .docx в Markdown
Система SHALL конвертировать загруженный `.docx`-файл в Markdown,
сохраняя структуру документа: заголовки MUST преобразовываться в
Markdown-заголовки соответствующего уровня (`#`–`######`), абзацы — в
текстовые блоки, таблицы — в Markdown-таблицы. Переносы строк и
множественные пробелы внутри ячейки таблицы MUST сворачиваться в один
пробел, чтобы строка таблицы оставалась однострочной. Объединённые
ячейки (horizontal/vertical merge) MUST эмитироваться в расплющенном
(flatten) виде: текст — один раз в первой позиции, повторные
виртуальные ячейки — пустыми, с сохранением числа колонок таблицы.
Конвертация MUST быть детерминированной: один и тот же входной файл даёт
одинаковый Markdown.

#### Scenario: Документ с заголовками и абзацами
- **Дано** загружен `.docx` с заголовком 1-го уровня «Отчёт» и абзацем «Текст отчёта»
- **Когда** выполняется конвертация в Markdown
- **То** результат содержит строку `# Отчёт` и абзац «Текст отчёта»

#### Scenario: Документ с таблицей
- **Дано** загружен `.docx` с таблицей из 2 строк и 2 столбцов
- **Когда** выполняется конвертация в Markdown
- **То** результат содержит Markdown-таблицу с теми же ячейками

#### Scenario: Таблица с объединёнными ячейками
- **Дано** загружен `.docx` с таблицей, содержащей горизонтально и вертикально объединённые ячейки
- **Когда** выполняется конвертация в Markdown
- **То** текст каждой объединённой ячейки присутствует один раз, повторные виртуальные ячейки пустые
- **И** число колонок во всех строках таблицы сохраняется
- **И** все строки таблицы однострочные

#### Scenario: Ячейка таблицы с переносом строки
- **Дано** загружен `.docx` с таблицей, ячейка которой содержит перенос строки
- **Когда** выполняется конвертация в Markdown
- **То** содержимое ячейки сворачивается в одну строку с обычными пробелами

#### Scenario: Пустой документ
- **Дано** загружен `.docx` без содержимого
- **Когда** выполняется конвертация в Markdown
- **То** результат — пустой Markdown-документ, ошибки не возникает

#### Scenario: Повреждённый файл
- **Дано** загружен файл с расширением `.docx`, не являющийся валидным DOCX
- **Когда** выполняется конвертация в Markdown
- **То** возникает ошибка конвертации с понятным сообщением
- **И** задача сравнения завершается со статусом ошибки

### Requirement: Единая точка входа конвертации
Система SHALL выбирать конвертер по расширению файла через единую точку
входа, чтобы добавление новых форматов (например, `.xlsx`) не меняло
вызывающий код. Для расширения без зарегистрированного конвертера система
MUST возвращать ошибку «формат не поддерживается».

#### Scenario: Неподдерживаемое расширение
- **Дано** в системе зарегистрирован только конвертер `.docx`
- **Когда** запрашивается конвертация файла `data.xlsx`
- **То** возвращается ошибка «формат не поддерживается»
