# vision-ocr Specification

## Purpose

Чтение текста со страниц изображений настроенной моделью: мультимодальный
запрос страницы, параметры роли чтения, воспроизводимость вызовов, кэш и
деградация при недоступности модели.

## Requirements

### Requirement: Использование настроенной модели для чтения страниц
Система SHALL читать страницы изображений той же моделью, что используется для
классификации фрагментов: имя, адрес и ключ API MUST браться из существующих
настроек модели, отдельной конфигурации модели для чтения страниц MUST NOT
требоваться. Параметры вызова, отличающиеся от классификации, MUST задаваться
отдельными настройками роли чтения страниц: таймаут запроса и число
одновременных запросов к модели. Настройки роли чтения страниц MUST NOT влиять
на параметры вызовов классификации, а параметры классификации MUST NOT влиять
на вызовы чтения страниц. Незаданное имя модели MUST приводить к понятной
ошибке конфигурации при чтении сканированного документа, а не к молчаливой
пустой конвертации.

#### Scenario: Чтение страниц настроенной моделью
- **Дано** заданы `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL`
- **Когда** выполняется чтение страницы изображения
- **То** запрос отправляется модели `LLM_MODEL` по адресу `LLM_BASE_URL`

#### Scenario: Настройки роли не влияют на классификацию
- **Дано** заданы параметры роли чтения страниц, отличные от параметров классификации
- **Когда** выполняется классификация фрагмента
- **То** классификация использует параметры по умолчанию для своей роли
- **И** настройки роли чтения страниц не применяются

#### Scenario: Не задано имя модели
- **Дано** имя модели не задано и выполняется конвертация сканированного PDF
- **Когда** выполняется конвертация
- **То** возвращается понятная ошибка конфигурации

#### Scenario: Незаданное имя модели не влияет на .docx
- **Дано** имя модели не задано и выполняется конвертация файла `.docx`
- **Когда** выполняется конвертация
- **То** конвертация завершается успешно

### Requirement: Мультимодальный запрос страницы
Система SHALL передавать страницу модели как изображение в составе
одного запроса, содержащего ровно одну страницу. Параметры генерации MUST
быть настроены на воспроизводимый результат: температура MUST быть нулевой,
а версия системной инструкции MUST фиксироваться вместе с результатом. Кэш
страницы MUST включать версию инструкции, чтобы изменение инструкции
инвалидировало ранее прочитанные страницы.

Системная инструкция, передаваемая модели с каждой страницей, MUST
требовать дословного распознавания текста страницы и MUST явно запрещать
модели суммировать, пересказывать, сокращать или перефразировать
содержимое страницы. Инструкция MUST требовать переноса всех видимых
фрагментов текста — включая заголовки, абзацы, таблицы, колонтитулы,
сноски и мелкий шрифт — без пропусков и без собственных добавлений
модели. Изменение текста системной инструкции MUST сопровождаться
повышением её версии по умолчанию, чтобы ранее прочитанные страницы
перечитывались с новой инструкцией, а не брались из кэша.

#### Scenario: Запрос одной страницы
- **Дано** страница отрендерена в изображение
- **Когда** выполняется чтение страницы
- **То** модель получает один запрос с текстовой инструкцией и одним изображением этой страницы

#### Scenario: Несколько страниц документа
- **Дано** документ состоит из трёх страниц, подлежащих чтению
- **Когда** выполняется чтение документа
- **То** выполнено три отдельных запроса, по одному на страницу

#### Scenario: Инструкция требует дословного переноса
- **Дано** выполняется чтение страницы сканированного документа
- **Когда** модели отправляется системная инструкция
- **То** инструкция требует дословного переноса текста страницы
- **И** инструкция запрещает суммирование, пересказ и сокращение содержимого

#### Scenario: Изменение текста инструкции повышает версию по умолчанию
- **Дано** текст системной инструкции изменён по сравнению с предыдущей версией
- **Когда** применяется конфигурация по умолчанию (переменная окружения не задана)
- **То** версия инструкции по умолчанию выше предыдущей
- **И** страницы, прочитанные со старой версией, перечитываются, а не берутся из кэша

### Requirement: Кэш прочитанных страниц
Результат чтения страницы MUST сохраняться в кэше. Ключ кэша MUST однозначно
определяться содержимым изображения страницы, именем модели и версией
инструкции. При наличии записи в кэше чтение MUST возвращать кэшированный
результат без обращения к модели. Повторное сравнение двух документов, где
часть страниц не менялась, MUST приводить к отсутствию запросов к модели по
этим страницам.

#### Scenario: Повторное сравнение тех же страниц
- **Дано** сканированные страницы уже прочитаны и сохранены в кэш
- **Когда** выполняется повторная конвертация тех же страниц
- **То** чтение возвращает кэшированный результат
- **И** обращений к модели не происходит

#### Scenario: Изменение инструкции
- **Дано** страница прочитана и её результат сохранён в кэш
- **Когда** версия инструкции изменена и страница запрошена снова
- **То** страница читается заново, а не берётся из кэша

### Requirement: Деградация при недоступности модели
Если модель недоступна или возвращает непригодный ответ, чтение
страницы MUST завершаться неудачей для этой страницы без отмены всего
сравнения: страница считается не прочитанной и даёт пустой список блоков.
Результат сравнения в таком случае MUST содержать признак деградации,
а интерфейс MUST показывать уведомление о деградированном режиме. Повторные
попытки чтения одной страницы MUST быть ограничены по числу. Причина
недоступности модели MUST записываться в журнал, чтобы деградацию можно было
различить без догадок: сетевая ошибка, таймаут и непригодный ответ — разные
причины с разными последствиями.

#### Scenario: Модель недоступна
- **Дано** модель недоступна по сети
- **Когда** выполняется конвертация сканированного документа
- **То** непрочитанные страницы дают пустой список блоков
- **И** задача завершается статусом «готово» с признаком деградации
- **И** интерфейс показывает уведомление о деградированном режиме
- **И** причина недоступности записана в журнал

#### Scenario: Непригодный ответ модели
- **Дано** модель вернула ответ, из которого нельзя получить ни одного блока
- **Когда** выполняется чтение страницы
- **То** страница помечается как не прочитанная
- **И** результат сравнения помечается признаком деградации
- **И** факт непригодного ответа записан в журнал
