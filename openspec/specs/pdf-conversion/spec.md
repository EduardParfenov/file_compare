# pdf-conversion Specification

## Purpose

Конвертация PDF-файлов в упорядоченный список блоков документа — двумя
ветками в зависимости от наличия текстового слоя: детерминированной без
участия модели и через модель для сканированных документов.

## Requirements

### Requirement: Выбор ветки конвертации PDF
Система SHALL выбирать ветку конвертации PDF по наличию текстового слоя.
PDF с текстовым слоем MUST конвертироваться детерминированно и без обращения
к моделям. PDF без текстового слоя MUST конвертироваться чтением страниц
моделью. Наличие текстового слоя определяется единожды для всего
документа, независимо от полноты слоя. Повреждённый или нечитаемый PDF MUST
давать ошибку конвертации с понятным сообщением.

#### Scenario: Родной PDF с текстовым слоем
- **Дано** загружен PDF, созданный в текстовом редакторе и содержащий текстовый слой
- **Когда** выполняется конвертация
- **То** выбрана ветка извлечения текстового слоя
- **И** модель не вызывается ни разу

#### Scenario: Скан без текстового слоя
- **Дано** загружен PDF, каждая страница которого является изображением без текстового слоя
- **Когда** выполняется конвертация
- **То** выбрана ветка чтения страниц моделью

#### Scenario: Скан с наложенным текстовым слоем
- **Дано** загружен скан, поверх изображения которого записан распознанный текстовый слой
- **Когда** выполняется конвертация
- **То** выбрана ветка извлечения текстового слоя, а не ветка чтения моделью

#### Scenario: Повреждённый PDF
- **Дано** загружен файл с расширением `.pdf`, не являющийся корректным PDF
- **Когда** выполняется конвертация
- **То** возвращается ошибка конвертации с понятным сообщением

### Requirement: Блоки документа с текстовым слоем
PDF с текстовым слоем MUST конвертироваться в блоки того же контракта, что и
`.docx`: текст для сравнения, HTML-представление для отображения, список
изображений. Заголовки, абзацы и строки таблиц MUST становиться отдельными
блоками в порядке следования в документе. Встроенные в PDF изображения
MUST извлекаться как изображения блоков с подписью содержимого, чтобы
замена картинки при неизменном тексте распознавалась существующим механизмом
сравнения изображений. Координаты слов MUST извлекаться и сохраняться в блоке,
поскольку они используются для привязки кропов визуально изменённых областей.

#### Scenario: Абзацы и заголовки родного PDF
- **Дано** загружен PDF с заголовком «Отчёт» и абзацем «Текст отчёта»
- **Когда** выполняется конвертация
- **То** результат содержит два блока в порядке следования с текстами «Отчёт» и «Текст отчёта»
- **И** каждый блок содержит текст, HTML-представление и список изображений

#### Scenario: Таблица в родном PDF
- **Дано** загружен PDF, содержащий таблицу
- **Когда** выполняется конвертация
- **То** каждая строка таблицы становится отдельным блоком в формате строки markdown-таблицы
- **И** HTML-представление блока содержит элементы ячеек в том же порядке

#### Scenario: Встроенное изображение в родном PDF
- **Дано** загружен PDF, в абзац которого встроено изображение
- **Когда** выполняется конвертация
- **То** блок этого абзаца содержит изображение с подписью содержимого

### Requirement: Чтение страниц определяется парой документов
Подлежащие чтению страницы MUST определяться совместно для двух
документов: страницы, совпавшие визуально, MUST NOT отправляться модели и
MUST NOT давать блоков. Определение подлежащих чтению страниц MUST
выполняться до первого обращения к модели. Страница, присутствующая только
в одном из документов, MUST читаться с единственной стороны. Страница, которую
не удалось прочитать, MUST NOT учитываться как неизменённая и MUST
отображаться как требующая чтения.

#### Scenario: Совпавшая страница не читается
- **Дано** страница 4 обоих документов совпала визуально
- **Когда** выполняется конвертация пары
- **То** страница 4 не отправляется модели ни с одной стороны
- **И** страница 4 не даёт блоков

#### Scenario: Определение до обращения к модели
- **Дано** из 30 страниц совпали 27
- **Когда** выполняется конвертация пары
- **То** страницы сопоставлены до первого обращения к модели
- **И** прочитаны только 3 изменившиеся страницы с обеих сторон

#### Scenario: Непрочитанная страница не считается неизменённой
- **Дано** страница 6 не удалась для чтения моделью
- **Когда** формируется результат
- **То** страница 6 не учитывается как совпавшая и требует внимания

### Requirement: Блоки сканированного документа из вывода модели чтения страниц
Каждая подлежащая чтению страница сканированного документа MUST
отправляться модели отдельным запросом. Разбор ответа модели MUST выделять в отдельные блоки
заголовки, абзацы и строки markdown-таблиц, сохраняя порядок следования на
странице. Строка markdown-таблицы MUST распознаваться как блок таблицы и
получать пословную подсветку по ячейкам существующим механизмом. Страница,
из которой не удалось получить ни одного блока, MUST давать пустой список
блоков и помечаться как не прочитанная, а не приводить к ошибке конвертации.

#### Scenario: Страница с абзацами
- **Дано** модель вернула для страницы markdown с заголовком и двумя абзацами
- **Когда** выполняется конвертация
- **То** страница даёт три блока в порядке: заголовок, первый абзац, второй абзац

#### Scenario: Таблица в ответе модели
- **Дано** модель вернула для страницы markdown-таблицу
- **Когда** выполняется конвертация
- **То** строки таблицы становятся блоками строк markdown-таблицы
- **И** в результате они отображаются как HTML-таблица с подсветкой по ячейкам

#### Scenario: Пустой ответ модели
- **Дано** модель вернула для страницы пустой ответ
- **Когда** выполняется конвертация
- **То** страница даёт пустой список блоков и помечается как не прочитанная
- **И** конвертация всего документа завершается успешно

### Requirement: Согласованность HTML-представления и текста блока
Для каждого блока MUST выполняться инвариант: текстовое содержимое
HTML-представления совпадает с текстом блока. HTML-представление MUST
строиться из нормализованного текста блока. Если ответ модели содержит
разметку, которую невозможно привести к этому инварианту, блок MUST быть
собран как plain text без потери текста.

#### Scenario: Заголовок из markdown
- **Дано** модель вернула строку `# Заголовок`
- **Когда** формируется блок
- **То** текст блока равен «Заголовок»
- **И** HTML-представление использует тег заголовка и содержит только текст «Заголовок»

#### Scenario: Разметка, не сводимая к тексту
- **Дано** модель вернула блок, HTML-представление которого не может быть построено с сохранением текста
- **Когда** формируется блок
- **То** блок получает HTML-представление из экранированного текста блока
- **И** текст блока не изменяется

### Requirement: Метаданные страницы в блоке
Блок документа, полученный из PDF, MUST содержать номер страницы, с которой
он происходит, в необязательном поле `page` (нумерация с единицы). Номер
страницы MUST использоваться только для отображения и MUST NOT влиять на
вычисление различий: вставка или удаление страницы MUST NOT приводить к
помечке прочих блоков как изменённых. Блоки, полученные из документов других
форматов, MUST NOT содержать поле `page`.

#### Scenario: Блок скана со страницей
- **Дано** блок прочитан со страницы 3 сканированного документа
- **Когда** формируется результат сравнения
- **То** строка результата для этого блока содержит номер страницы 3 для своей стороны
- **И** номер страницы не участвует в вычислении различий

#### Scenario: Вставка страницы в середину документа
- **Дано** в файл 2 в середину документа вставлена новая страница
- **Когда** выполняется сравнение
- **То** содержимое страниц после вставки не помечено как изменённое из-за сдвига нумерации

#### Scenario: Блок документа .docx
- **Дано** выполняется сравнение двух файлов `.docx`
- **Когда** формируется результат
- **То** строки результата не содержат номера страницы

### Requirement: Показ страниц в результате сравнения
Результат сравнения PDF-документов MUST показывать все блоки страниц,
подлежавших чтению, а не только блоки, затронутые различием: окружение
изменения MUST быть видимо пользователю. Номер страницы MUST отображаться
для блока. Страница, признанная неизменной, MUST отображаться только
свёрнутым диапазоном, и её содержимое MUST NOT выводиться строками результата,
в том числе когда текст страниц доступен без обращения к модели. Непрерывный
диапазон страниц, не содержащий изменений, MUST отображаться свёрнутым и
MUST раскрываться по требованию пользователя с добычей текста страниц.
При отсутствии различий по тексту и по изображению MUST отображаться
сообщение о полном совпадении документов.

#### Scenario: Изменённая страница показана целиком
- **Дано** на странице 5 изменён один абзац среди прочих
- **Когда** отображается результат
- **То** показаны все блоки страницы 5, а подсветка различий — на изменённых

#### Scenario: Диапазон совпавших страниц свёрнут
- **Дано** страницы 6–11 совпали визуально
- **Когда** отображается результат
- **То** вместо содержимого этих страниц показана свёрнутая строка диапазона

#### Scenario: Совпавшая страница при текстовом слое не дублируется
- **Дано** оба файла имеют текстовый слой, страница 6 совпала визуально,
  а страница 7 отличается
- **Когда** отображается результат
- **То** страница 6 представлена свёрнутой строкой диапазона
- **И** строки результата не содержат блоков страницы 6

#### Scenario: Документы совпадают полностью
- **Дано** все страницы совпали визуально и различий по тексту нет
- **Когда** отображается результат
- **То** показано сообщение о полном совпадении документов

### Requirement: Определённость конвертации PDF
Конвертация ветки текстового слоя MUST быть детерминированной: один и тот же
файл даёт одинаковый список блоков. Конвертация ветки чтения моделью MUST
быть детерминированной в пределах кэша: повторная конвертация страницы, для
которой в кэше есть результат, MUST давать те же блоки, что и первый вызов,
без обращения к модели.

#### Scenario: Повторная конвертация родного PDF
- **Дано** PDF с текстовым слоем уже конвертирован один раз
- **Когда** выполняется конвертация того же файла повторно
- **То** список блоков совпадает с первым результатом

#### Scenario: Повторная конвертация скана при заполненном кэше
- **Дано** сканированный PDF уже конвертирован, страницы есть в кэше
- **Когда** выполняется конвертация того же файла повторно
- **То** список блоков совпадает с первым результатом
- **И** модель не вызывается
