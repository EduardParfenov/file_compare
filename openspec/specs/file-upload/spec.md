# file-upload Specification

## Purpose

Загрузка двух версий документа на сервер через веб-страницу (кнопки выбора
и drag-and-drop) с валидацией формата и размера, чтобы подготовить файлы
к сравнению.

## Requirements

### Requirement: Загрузка файла через API
Система SHALL предоставлять эндпоинт `POST /api/upload`, принимающий один
файл (multipart/form-data, поле `file`), сохраняющий его в каталог
`UPLOAD_DIR` под уникальным именем и возвращающий JSON с идентификатором
загрузки и исходным именем файла. Эндпоинт MUST отклонять файлы с
расширением вне списка `ALLOWED_EXTENSIONS` (код 400) и файлы,
превышающие `MAX_CONTENT_LENGTH` (код 413).

#### Scenario: Успешная загрузка .docx-файла
- **Дано** на сервере настроен каталог `UPLOAD_DIR` и `ALLOWED_EXTENSIONS` содержит `.docx`
- **Когда** клиент отправляет `POST /api/upload` с файлом `report_v1.docx`
- **То** ответ имеет код 200 и содержит `upload_id` и имя файла `report_v1.docx`
- **И** файл сохранён в каталоге `UPLOAD_DIR`

#### Scenario: Отклонение неподдерживаемого формата
- **Дано** `ALLOWED_EXTENSIONS` содержит только `.docx`
- **Когда** клиент отправляет `POST /api/upload` с файлом `notes.txt`
- **То** ответ имеет код 400 и JSON с полем `error`
- **И** файл не сохраняется в `UPLOAD_DIR`

#### Scenario: Отклонение файла без поля file
- **Когда** клиент отправляет `POST /api/upload` без файла
- **То** ответ имеет код 400 и JSON с полем `error`

#### Scenario: Отклонение слишком большого файла
- **Дано** `MAX_CONTENT_LENGTH` ограничивает размер загрузки
- **Когда** клиент отправляет `POST /api/upload` с файлом, превышающим лимит
- **То** ответ имеет код 413

### Requirement: Выбор файлов на веб-странице
Веб-страница SHALL содержать две зоны загрузки — «Файл 1» и «Файл 2» — с
кнопками «Открыть файл 1» и «Открыть файл 2», а также MUST поддерживать
перетаскивание файла из проводника в соответствующую зону (drag-and-drop).
После успешной загрузки зона MUST отображать имя загруженного файла.
При ошибке валидации страница MUST показать сообщение об ошибке и не
считать файл загруженным.

#### Scenario: Выбор файла кнопкой
- **Дано** пользователь открыл главную страницу
- **Когда** он нажимает «Открыть файл 1» и выбирает `report_v1.docx`
- **То** файл отправляется на `POST /api/upload`
- **И** в зоне «Файл 1» отображается имя `report_v1.docx`

#### Scenario: Перетаскивание файла в зону загрузки
- **Дано** пользователь открыл главную страницу
- **Когда** он перетаскивает `report_v2.docx` из проводника в зону «Файл 2»
- **То** файл отправляется на `POST /api/upload`
- **И** в зоне «Файл 2» отображается имя `report_v2.docx`

#### Scenario: Ошибка при неподдерживаемом формате в UI
- **Дано** пользователь открыл главную страницу
- **Когда** он выбирает файл `archive.zip` в любой зоне загрузки
- **То** отображается сообщение об ошибке о неподдерживаемом формате
- **И** зона загрузки остаётся пустой

### Requirement: Активация кнопки «Начать сравнение»
Кнопка «Начать сравнение» SHALL быть неактивна (disabled), пока не
загружены оба файла, и MUST становиться активной только после успешной
загрузки файла 1 и файла 2.

#### Scenario: Кнопка неактивна при одном загруженном файле
- **Дано** загружен только «Файл 1»
- **Когда** пользователь смотрит на кнопку «Начать сравнение»
- **То** кнопка неактивна

#### Scenario: Кнопка активна после загрузки обоих файлов
- **Дано** успешно загружены «Файл 1» и «Файл 2»
- **Когда** пользователь смотрит на кнопку «Начать сравнение»
- **То** кнопка активна

### Requirement: Поддержка формата .pdf при загрузке
Система SHALL принимать файлы `.pdf` для загрузки и сравнения. Значение по
умолчанию `ALLOWED_EXTENSIONS` MUST включать `.pdf` наряду с `.docx`.
Файл `.pdf`, расширение которого не входит в `ALLOWED_EXTENSIONS`, MUST
отклоняться с кодом 400 и не сохраняться в `UPLOAD_DIR`. Значение по
умолчанию `MAX_CONTENT_LENGTH` MUST быть достаточным для загрузки типичного
многостраничного сканированного документа; файл превышающего лимит MUST
отклоняться с кодом 413. Веб-страница MUST указывать `.pdf` среди
поддерживаемых форматов при выборе файла.

#### Scenario: Успешная загрузка PDF
- **Дано** на сервере настроен каталог `UPLOAD_DIR` и `ALLOWED_EXTENSIONS` содержит `.pdf`
- **Когда** клиент отправляет `POST /api/upload` с файлом `contract_v1.pdf`
- **То** ответ имеет код 200 и содержит `upload_id` и имя файла `contract_v1.pdf`
- **И** файл сохранён в каталоге `UPLOAD_DIR`

#### Scenario: Отклонение PDF вне списка разрешённых расширений
- **Дано** `ALLOWED_EXTENSIONS` содержит только `.docx`
- **Когда** клиент отправляет `POST /api/upload` с файлом `contract_v1.pdf`
- **То** ответ имеет код 400 и JSON с полем `error`
- **И** файл не сохраняется в `UPLOAD_DIR`

#### Scenario: Скан превышает лимит размера
- **Дано** `MAX_CONTENT_LENGTH` ограничивает размер загрузки
- **Когда** клиент отправляет многостраничный сканированный PDF, превышающий лимит
- **То** ответ имеет код 413

#### Scenario: Форматы в элементе выбора файла
- **Дано** пользователь открыл веб-страницу
- **Когда** отображается зона загрузки файла
- **То** элемент выбора файла допускает `.docx` и `.pdf`
