## MODIFIED Requirements

### Requirement: Загрузка файла через API
Система SHALL предоставлять эндпоинт `POST /api/upload`, принимающий один
файл (multipart/form-data, поле `file`), сохраняющий его в каталог
`UPLOAD_DIR` под уникальным именем и возвращающий JSON с идентификатором
загрузки и исходным именем файла. Расширение файла MUST определяться по
исходному имени, переданному клиентом, до какой-либо санитизации имени при
сохранении. Эндпоинт MUST отклонять файлы с расширением вне списка
`ALLOWED_EXTENSIONS` (код 400) и файлы, превышающие `MAX_CONTENT_LENGTH`
(код 413). Файлы с именами, содержащими не-ASCII символы (например,
кириллицу), MUST приниматься, если расширение входит в `ALLOWED_EXTENSIONS`;
имя файла в ответе MUST быть исходным именем, переданным клиентом.

#### Scenario: Успешная загрузка .docx-файла
- **Дано** на сервере настроен каталог `UPLOAD_DIR` и `ALLOWED_EXTENSIONS` содержит `.docx`
- **Когда** клиент отправляет `POST /api/upload` с файлом `report_v1.docx`
- **То** ответ имеет код 200 и содержит `upload_id` и имя файла `report_v1.docx`
- **И** файл сохранён в каталоге `UPLOAD_DIR`

#### Scenario: Успешная загрузка файла с кириллическим именем
- **Дано** `ALLOWED_EXTENSIONS` содержит `.docx`
- **Когда** клиент отправляет `POST /api/upload` с файлом `документ.docx`
- **То** ответ имеет код 200 и содержит `upload_id` и имя файла `документ.docx`
- **И** файл сохранён в каталоге `UPLOAD_DIR` с расширением `.docx`

#### Scenario: Отклонение неподдерживаемого формата
- **Дано** `ALLOWED_EXTENSIONS` содержит только `.docx`
- **Когда** клиент отправляет `POST /api/upload` с файлом `notes.txt`
- **То** ответ имеет код 400 и JSON с полем `error`
- **И** файл не сохраняется в `UPLOAD_DIR`

#### Scenario: Отклонение файла с кириллическим именем неподдерживаемого формата
- **Дано** `ALLOWED_EXTENSIONS` содержит только `.docx`
- **Когда** клиент отправляет `POST /api/upload` с файлом `заметки.txt`
- **То** ответ имеет код 400 и JSON с полем `error`
- **И** файл не сохраняется в `UPLOAD_DIR`

#### Scenario: Отклонение файла без поля file
- **Когда** клиент отправляет `POST /api/upload` без файла
- **То** ответ имеет код 400 и JSON с полем `error`

#### Scenario: Отклонение слишком большого файла
- **Дано** `MAX_CONTENT_LENGTH` ограничивает размер загрузки
- **Когда** клиент отправляет `POST /api/upload` с файлом, превышающим лимит
- **То** ответ имеет код 413
