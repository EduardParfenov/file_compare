# diff-viewer Delta

## ADDED Requirements

### Requirement: Адаптивная ширина страницы
Веб-страница SHALL занимать 90% ширины окна браузера, но не более 1920px,
чтобы широкие таблицы документов умещались в панелях diff viewer. При
изменении ширины окна браузера раскладка MUST адаптироваться
автоматически, без перезагрузки страницы и без JavaScript. На экранах,
где 90% ширины окна превышает 1920px, страница MUST центрироваться по
горизонтали.

#### Scenario: Широкоформатный монитор
- **Дано** окно браузера шириной 1920px и более
- **Когда** открыта страница сравнения
- **То** содержимое страницы занимает 90% ширины окна (до 1920px) и центрировано
- **И** панели diff viewer используют доступную ширину для отображения таблиц

#### Scenario: Изменение ширины окна
- **Дано** страница сравнения открыта
- **Когда** пользователь изменяет ширину окна браузера
- **То** ширина раскладки адаптируется к новой ширине окна автоматически

### Requirement: Центрированная колонка контролов
Зоны загрузки файлов, кнопка «Начать сравнение», степпер этапов и
уведомления (об ошибке и о деградированном режиме) SHALL размещаться в
центрированной колонке ограниченной ширины (не более ~1150px), сохраняя
пропорции зон загрузки как при ширине страницы 1200px. Кнопка «Начать
сравнение» и степпер MUST быть выровнены по центру колонки. Панели
diff viewer MUST NOT ограничиваться шириной этой колонки и SHALL
занимать всю ширину страницы.

#### Scenario: Контролы по центру при широком окне
- **Дано** окно браузера шириной 1920px
- **Когда** открыта страница сравнения
- **То** зоны загрузки, кнопка сравнения и степпер центрированы и не шире ~1150px
- **И** панели diff viewer занимают всю ширину страницы

#### Scenario: Пропорции зон загрузки
- **Дано** страница открыта в широком окне
- **Когда** отображаются зоны загрузки файлов
- **То** каждая зона имеет ширину, сопоставимую с шириной при странице 1200px (~570px)

### Requirement: Центрированная шапка страницы
Заголовок «Сравнение версий документа» и подпись «Загрузите две версии
документа (.docx) для сравнения» SHALL отображаться по центру страницы.
Подпись MUST отображаться без точки в конце.

#### Scenario: Отображение шапки
- **Дано** открыта страница сравнения
- **Когда** страница отрисована
- **То** заголовок и подпись выровнены по центру страницы
- **И** подпись оканчивается словом «сравнения» без точки
