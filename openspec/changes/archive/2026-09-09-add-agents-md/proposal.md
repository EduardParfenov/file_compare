# Предложение: добавить AGENTS.md

Уровень: исправление

## Why

В корне проекта нет `AGENTS.md` — стандартного файла инструкций для
AI-агентов. Сейчас сведения о проекте разнесены по `README.md`,
`openspec/config.yaml` (context) и `REVIEW.md`; агенту приходится
собирать их по кускам. Единый `AGENTS.md` даст агентам предсказуемую
точку входа с правилами, структурой и командами проекта.

## What Changes

- Создаётся `AGENTS.md` в корне проекта со сводкой, необходимой агенту
  для работы: назначение и стек; структура каталогов; установка, запуск
  и тесты; конфигурация через env; конвенции кода и языка; правила
  безопасности; workflow OpenSpec (change-предложения, правило строки
  «уровень: …» в proposal, архивация); запрет читать каталог `input/`;
  указание, что `uploads/` не коммитится; ссылки на `README.md`,
  `REVIEW.md` и `openspec/`.
- Источники правды не дублируются: `AGENTS.md` содержит краткую сводку
  и ссылается на `README.md` / `openspec/config.yaml` / `REVIEW.md` за
  деталями, чтобы не плодить расхождения.
- В `README.md` актуализируется описание опроса статуса: «раз в
  3 секунды» → «каждую 1 секунду» (устарело после архивированного
  change `poll-status-every-second`).
- Поведение системы и capability-спецификации не меняются — change
  оформлен с `skip_specs: true`.
