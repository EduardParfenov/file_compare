# Предложение: отображение таблиц как HTML-таблиц

> Оформлено задним числом: реализация уже выполнена,
> основная спека `diff-viewer` синхронизирована.

## Why

Строки таблиц отображались в diff viewer как сырой Markdown
(`| Товар | Цена |`) — неинформативно для пользователя. Дизайн выбран с
оглядкой на будущую поддержку `.xlsx`: таблица передаётся в API
структурно (строки × ячейки), а не строкой с пайпами, поэтому конвертер
xlsx позже подключится к тому же пайплайну без изменений фронта.

## What Changes

- API результата: у блоков-строк таблиц появляется структура `cells`
  (список ячеек); служебная строка-разделитель помечается `sep` и не
  отображается как данные; у изменённых пар строк — `cell_segments`
  (пословный diff по каждой ячейке).
- Diff viewer: подряд идущие строки таблицы собираются в HTML-таблицу
  (первая строка — шапка `<th>`); добавленная/удалённая строка — цветной
  `<tr>`, изменённая — пословная подсветка внутри ячеек (git-стиль).
- Крайние случаи: экранированный `\|` внутри ячейки не разрезает её;
  разное число колонок в файлах дополняется пустыми ячейками — таблица
  не «разваливается».

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `diff-viewer`: таблицы отображаются как HTML-таблицы со структурной
  подсветкой.

## Impact

- **Код**: `app/services/diffing.py` (`parse_table_row`,
  `is_table_separator`, `is_table_row`), `app/services/jobs.py`
  (обогащение блоков `cells`/`sep`, per-cell `cell_segments`),
  `app/static/app.js` (группировка строк в `<table>`),
  `app/static/style.css` (стили таблиц).
- **API**: обратносовместимое расширение — новые необязательные поля
  `cells` / `sep` / `cell_segments` у блоков результата.
- **Тесты**: парсер ячеек (включая `\|`), распознавание сепаратора,
  e2e таблицы с изменённой ячейкой и с разным числом колонок;
  рендер — headless Chrome.
