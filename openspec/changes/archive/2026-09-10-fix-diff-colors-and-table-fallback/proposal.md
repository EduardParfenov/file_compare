# Proposal: fix-diff-colors-and-table-fallback

уровень: исправление

## Why

Аудит (REVIEW.md) выявил расхождения кода и комментариев со спекой
diff-viewer: fallback табличной ветки оставляет изменённые ячейки вообще
без подсветки (`_plain_segments`, тип `same`), а комментарии в
`app/static/app.js` и `tests/test_jobs.py` описывают жёлтую подсветку,
запрещённую спекой. Продуктовое решение — двухцветная модель
(красный/зелёный) — принято; нужно довести до неё спеку (правило fallback
для таблиц), код и тесты.

## What Changes

- Спека diff-viewer: добавить правило fallback для таблиц — при
  недоступности пословного diff изменённая ячейка подсвечивается целиком:
  красным в панели файла 1 (старая версия), зелёным в панели файла 2
  (новая версия), по общему правилу fallback для обычных блоков.
- `app/services/jobs.py`: в табличной ветке fallback при отсутствии
  пословных сегментов (`inline_diff` вернул `None`) ячейка представляется
  одним сегментом `del` (файл 1) / `add` (файл 2) вместо `_plain_segments`
  без подсветки.
- `app/static/app.js`: исправить комментарий (стр. ~191) на описание
  двухцветной модели. Проверить, что в подсветке различий нет жёлтого.
- `app/static/style.css`: проверить, что в классах подсветки различий
  (`seg-*`, `change-*`, `placeholder-*`) жёлтый не используется; жёлтый
  допустим только в палитре интерфейса (рамки, степпер, уведомления).
- `tests/test_jobs.py`: исправить комментарий (стр. ~250); добавить тест
  fallback таблиц (изменённая строка без пословного diff → ячейки
  `del`/`add`) и тест-фиксацию двухцветной модели (в результатах задач
  только типы подсветки «красный»/`del` и «зелёный»/`add`).

## Capabilities

### New Capabilities

(пусто)

### Modified Capabilities

- `diff-viewer`: требование «Отображение таблиц как HTML-таблиц»
  дополняется правилом fallback: при недоступности пословного diff
  изменённые ячейки подсвечиваются красным/зелёным фоном целиком.

## Impact

- `app/services/jobs.py` — fallback табличной ветки `_build_rows`.
- `app/static/app.js`, `app/static/style.css` — комментарии и проверка
  отсутствия жёлтого в подсветке различий.
- `tests/test_jobs.py` — комментарий, новые тесты fallback и двухцветной
  модели.
- `openspec/specs/diff-viewer/spec.md` — правило fallback для таблиц.
- Контракт данных результата задачи не меняется: используются
  существующие типы сегментов `del`/`add` в `cell_segments`.
- Не затрагиваются: `inline_diff`, ретраи, этапы обработки, парсинг,
  остальные замечания REVIEW.md (отдельными change'ами).
