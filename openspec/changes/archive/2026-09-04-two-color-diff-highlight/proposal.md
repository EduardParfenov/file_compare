# Proposal: two-color-diff-highlight

## Why

Жёлтая подсветка «изменено» неоднозначна и смущает: непонятно, что именно
произошло со словом или блоком. Двухцветная модель (красный = удалено,
зелёный = добавлено) — стандарт де-факто (git, GitHub, GitLab, VS Code):
«изменено» однозначно читается как «удалена старая версия + добавлена
новая».

## What Changes

- Понятие «изменённое слово» (`chg`) убирается из пословного diff:
  старая версия слова подсвечивается красным в файле 1, новая — зелёным
  в файле 2. Эвристика похожести слов (`SIMILARITY_THRESHOLD` для
  токенов, `_match_pairs` внутри `replace`) больше не используется.
- Fallback изменённого блока (пословный diff недоступен): вместо жёлтого
  фона — красный фон в панели файла 1 и зелёный в панели файла 2;
  то же для строк таблиц. Контракт данных не меняется, реализация —
  CSS-правила по панелям.
- **BREAKING (визуально)**: жёлтая подсветка различий удаляется полностью.
  Жёлтый в хроме интерфейса (рамки, степпер, уведомление о деградации)
  сохраняется — палитра остаётся желто-зелено-серой.

## Capabilities

### New Capabilities

(пусто)

### Modified Capabilities

- `diff-viewer`: изменяются требования «Цветовая подсветка различий»
  (двухцветная модель, «изменено» = красный + зелёный) и «Отображение
  таблиц как HTML-таблиц» (изменённые ячейки — красный/зелёный).

## Impact

- `app/services/diffing.py` — упрощение `inline_diff` (без `chg`).
- `app/static/style.css` — удаление `.seg-chg`, панельные правила для
  `.change-changed`.
- `app/static/app.js` — не меняется (рендерит любой тип сегмента).
- `tests/test_diffing.py` — тесты на `chg` переписываются под `del`/`add`;
  `tests/test_jobs.py` — проверить ожидания сегментов.
