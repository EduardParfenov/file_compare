# Design: add-project-version

## Context

См. proposal.md — Why. В проекте нет `VERSION`/`pyproject.toml`/`__version__`.
Приложение — Flask-фабрика `create_app` (`app/__init__.py`), главная страница
`app/templates/index.html` рендерится роутом `index()`. Правило бампа версии
уже зафиксировано в AGENTS.md, но не имеет объекта.

## Goals / Non-Goals

Goals:
- Один файл `VERSION` — единственный источник версии (нет дублирования в
  коде и шаблоне).
- Версия видна в подвале главной страницы.

Non-Goals:
- Отображение версии в `/health` и API (не выбрано владельцем).
- Автоматический бамп версии (CI/хуки): бамп выполняется вручную при
  архивации change'а по правилу из спеки.
- `pyproject.toml`/пакетирование — проект не является устанавливаемым
  пакетом.

## Decisions

- **Только `VERSION` в корне, без `__version__` в коде.** Один источник
  истины; Python читает файл при старте. Альтернатива (`__version__`)
  дублировала бы значение или потребовала бы пакетных метаданных.
- **Чтение в `create_app`**: `Path(__file__).resolve().parent.parent /
  "VERSION"` → `app.config["APP_VERSION"]`; путь относительный к коду,
  соответствует конвенции «пути относительные или из конфигурации».
- **Отсутствие/нечитаемость файла → `"0.0.0-dev"`, без падения.** Приложение
  не должно ломаться в окружении без файла (например, частичный деплой);
  файл закоммичен, поэтому в норме ветка не срабатывает. Альтернатива
  (fail fast, как `LLM_EXTRA_BODY`) отклонена: версия — не критичная
  конфигурация.
- **Подвал `index.html`**: `<footer class="page-footer">Версия {{ version }}</footer>`;
  значение передаётся из роута `index()` (`render_template("index.html",
  version=current_app.config["APP_VERSION"])`). Минимальный стиль в
  `style.css`.
- **Начальная версия `0.1.0`** — выбор владельца; проект в стадии начальной
  разработки.

## Risks / Trade-offs

- [Бамп версии ручной — можно забыть] → правило в спеке + чек-лист
  архивации в AGENTS.md; при росте числа релизов добавить проверку в CI
  отдельным change'ом.
- [Запасное значение `0.0.0-dev` может маскировать потерю файла] → значение
  явно маркирует аномалию и видно в UI.

## Migration Plan

Миграции нет. Откат — удаление `VERSION` и правок. После архивации этого
change'а (уровень «исправление») версия становится `0.1.1`.
