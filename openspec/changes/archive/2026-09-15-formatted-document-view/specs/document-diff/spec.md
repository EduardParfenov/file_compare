## REMOVED Requirements

### Requirement: Разбиение Markdown на блоки
**Reason**: Разбиение документа на блоки переносится в конвертер
(markdown-прослойка устранена); diff-движок получает упорядоченные блоки
напрямую от конвертера.
**Migration**: Конвертер возвращает упорядоченный список блоков
(заголовок, абзац, строка таблицы); нормализация пробельных символов
сохраняется в diff-движке — см. требование «Нормализация блоков
документа».

## ADDED Requirements

### Requirement: Нормализация блоков документа
Система SHALL принимать от конвертера упорядоченную последовательность
текстовых блоков и нормализовать их перед сравнением: пробельные
символы (включая неразрывные пробелы) MUST сворачиваться в один обычный
пробел, блоки без содержимого после нормализации (ни текста, ни
изображений) MUST игнорироваться.
Порядок блоков MUST сохраняться. Гранулярность блоков (заголовок,
абзац, строка таблицы) определяется конвертером и MUST NOT
пересматриваться движком сравнения.

#### Scenario: Нормализация пробелов
- **Дано** блоки с неразрывными и повторными пробелами
- **Когда** выполняется нормализация перед сравнением
- **То** последовательности пробельных символов сворачиваются в один обычный пробел

#### Scenario: Пустые после нормализации блоки
- **Дано** блок, состоящий только из пробельных символов, без изображений
- **Когда** выполняется нормализация перед сравнением
- **То** этот блок исключён из сравнения

#### Scenario: Блок только с изображением
- **Дано** блок без текста, но с изображением
- **Когда** выполняется нормализация перед сравнением
- **То** этот блок сохраняется в сравнении

#### Scenario: Порядок блоков сохраняется
- **Дано** последовательность блоков от конвертера
- **Когда** выполняется нормализация перед сравнением
- **То** порядок непустых блоков соответствует порядку следования в документе
