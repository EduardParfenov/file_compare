# Proposal: harden-ocr-verbatim-prompt

уровень: исправление

## Why

Прогон `tests/real_model_check.py` на `qwen3-vl-8b` показал, что vision-модель при чтении страниц сканов **сокращает и пересказывает** текст вместо дословного переноса («ten banking days» → «ten days»; «0.1 percent is charged for each day of delay» → «0.1 percent is...»). На реальном договоре это источник ложных и пропущенных различий текстового diff. Проблема отложена в REVIEW.md как отдельный change: инструкция промпта требует ужесточения («дословно, без сокращений»).

## What Changes

- Ужесточение системной инструкции `SYSTEM_PROMPT` в `app/services/vision_ocr.py`: требование дословного переноса текста страницы, явный запрет на суммирование, пересказ, сокращение и paraphrasing, требование воспроизводить все видимые фрагменты текста (включая колонтитулы, сноски, мелкий шрифт).
- Повышение версии инструкции по умолчанию `PROMPT_VERSION` с `v1` на `v2` (и значения по умолчанию `OCR_PROMPT_VERSION` в `app/__init__.py`, `.env.example`, README): изменение текста инструкции MUST инвалидировать кэш страниц, поэтому дефолтная версия повышается вместе с текстом.
- Тесты: обновить/добавить проверки в `tests/test_vision_ocr.py`, фиксирующие обязательные элементы новой инструкции (дословность, запрет сокращений) и повышение версии по умолчанию.
- Актуализация документации: ограничение в README о пересказе модели (после ужесточения промпта формулировка смягчается, риск остаётся), запись в REVIEW.md о закрытии отложенной задачи.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `vision-ocr`: требование «Мультимодальный запрос страницы» дополняется: системная инструкция MUST требовать дословного распознавания текста и MUST запрещать модели суммировать, пересказывать или сокращать содержимое страницы.

## Impact

- Код: `app/services/vision_ocr.py` (`SYSTEM_PROMPT`, `PROMPT_VERSION`), `app/__init__.py` (значение по умолчанию `OCR_PROMPT_VERSION`).
- Конфигурация/документация: `.env.example`, `README.md` (таблица настроек и ограничения), `REVIEW.md` (закрытие отложенной задачи о пересказе).
- Тесты: `tests/test_vision_ocr.py` (контент инструкции, дефолтная версия).
- Поведение: запросы к VL-модели при чтении сканированных PDF уходят с новой инструкцией; кэш старых страниц (ключ включает версию инструкции) перестаёт попадаться при повышении дефолтной версии — страницы читаются заново. API и формат результатов не меняются.
