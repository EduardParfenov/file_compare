# Delta: vision-ocr

## MODIFIED Requirements

### Requirement: Мультимодальный запрос страницы
Система SHALL передавать страницу модели как изображение в составе
одного запроса, содержащего ровно одну страницу. Параметры генерации MUST
быть настроены на воспроизводимый результат: температура MUST быть нулевой,
а версия системной инструкции MUST фиксироваться вместе с результатом. Кэш
страницы MUST включать версию инструкции, чтобы изменение инструкции
инвалидировало ранее прочитанные страницы.

Системная инструкция, передаваемая модели с каждой страницей, MUST
требовать дословного распознавания текста страницы и MUST явно запрещать
модели суммировать, пересказывать, сокращать или перефразировать
содержимое страницы. Инструкция MUST требовать переноса всех видимых
фрагментов текста — включая заголовки, абзацы, таблицы, колонтитулы,
сноски и мелкий шрифт — без пропусков и без собственных добавлений
модели. Изменение текста системной инструкции MUST сопровождаться
повышением её версии по умолчанию, чтобы ранее прочитанные страницы
перечитывались с новой инструкцией, а не брались из кэша.

#### Scenario: Запрос одной страницы
- **Дано** страница отрендерена в изображение
- **Когда** выполняется чтение страницы
- **То** модель получает один запрос с текстовой инструкцией и одним изображением этой страницы

#### Scenario: Несколько страниц документа
- **Дано** документ состоит из трёх страниц, подлежащих чтению
- **Когда** выполняется чтение документа
- **То** выполнено три отдельных запроса, по одному на страницу

#### Scenario: Инструкция требует дословного переноса
- **Дано** выполняется чтение страницы сканированного документа
- **Когда** модели отправляется системная инструкция
- **То** инструкция требует дословного переноса текста страницы
- **И** инструкция запрещает суммирование, пересказ и сокращение содержимого

#### Scenario: Изменение текста инструкции повышает версию по умолчанию
- **Дано** текст системной инструкции изменён по сравнению с предыдущей версией
- **Когда** применяется конфигурация по умолчанию (переменная окружения не задана)
- **То** версия инструкции по умолчанию выше предыдущей
- **И** страницы, прочитанные со старой версией, перечитываются, а не берутся из кэша
