## MODIFIED Requirements

### Requirement: Рендер страниц PDF
Система SHALL отображать страницы PDF в изображения с разрешением, настраиваемым через переменную окружения `PDF_RENDER_DPI`. Рендер MUST выполняться постранично, без одновременного построения изображений всех страниц документа в памяти, и MUST NOT записывать промежуточные изображения на диск. Рендер MUST быть детерминированным: один и тот же файл при одном и том же разрешении даёт одинаковые изображения страниц. Значение `PDF_RENDER_DPI` из конфигурации MUST достигать функции рендера страниц. Повреждённая страница MUST приводить к ошибке конвертации с понятным сообщением, а не к пустому изображению.

#### Scenario: Рендер страницы
- **Дано** загружен PDF на несколько страниц
- **Когда** выполняется рендер страниц
- **То** получено изображение каждой страницы с заданным разрешением
- **И** промежуточные файлы на диске не создаются

#### Scenario: Разрешение рендера из конфигурации
- **Дано** задана переменная окружения `PDF_RENDER_DPI`
- **Когда** выполняется рендер страниц PDF
- **То** изображения получены с разрешением `PDF_RENDER_DPI`

#### Scenario: Повторяемость рендера
- **Дано** один и тот же PDF отрендерен дважды при одном разрешении
- **Когда** сравниваются изображения страниц
- **То** изображения совпадают

#### Scenario: Повреждённая страница
- **Дано** файл с расширением `.pdf`, содержащий повреждённую страницу
- **Когда** выполняется рендер этой страницы
- **То** возвращается ошибка с понятным сообщением
