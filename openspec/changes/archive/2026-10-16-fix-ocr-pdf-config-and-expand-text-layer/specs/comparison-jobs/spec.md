## MODIFIED Requirements

### Requirement: Ограничение объёма кропов в результате
Суммарный объём изображений визуально изменённых областей, передаваемых в результате задачи, MUST ограничиваться настраиваемым лимитом на документ, задаваемым переменной окружения `PDF_CROPS_MAX_BYTES`. Превышение лимита MUST приводить к отбрасыванию части кропов и к установке признака усечения кропов в результате. Ограничение кропов MUST NOT влиять на текст блоков, на вычисление различий и на классификацию фрагментов. Значение `PDF_CROPS_MAX_BYTES` из конфигурации MUST достигать функции формирования кропов при конвертации пары PDF.

#### Scenario: Кропы укладываются в лимит
- **Дано** суммарный объём кропов документа не превышает настроенный лимит `PDF_CROPS_MAX_BYTES`
- **Когда** формируется результат задачи
- **То** все кропы переданы в результате
- **И** признак усечения кропов не установлен

#### Scenario: Кропы превышают лимит
- **Дано** суммарный объём кропов документа превышает настроенный лимит `PDF_CROPS_MAX_BYTES`
- **Когда** формируется результат задачи
- **То** часть кропов отброшена по убыванию площади, а результат содержит признак усечения кропов
- **И** строки результата и их классы изменений не изменились

#### Scenario: Лимит кропов из конфигурации
- **Дано** задана переменная окружения `PDF_CROPS_MAX_BYTES`
- **Когда** выполняется конвертация пары PDF
- **То** суммарный объём кропов ограничен значением `PDF_CROPS_MAX_BYTES`
