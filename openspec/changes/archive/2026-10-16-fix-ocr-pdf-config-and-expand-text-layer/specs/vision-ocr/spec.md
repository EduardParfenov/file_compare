## MODIFIED Requirements

### Requirement: Использование настроенной модели для чтения страниц
Система SHALL читать страницы изображений той же моделью, что используется для классификации фрагментов: имя, адрес и ключ API MUST браться из существующих настроек модели, отдельной конфигурации модели для чтения страниц MUST NOT требоваться. Параметры вызова, отличающиеся от классификации, MUST задаваться отдельными настройками роли чтения страниц: таймаут запроса (`OCR_TIMEOUT`), версия системной инструкции (`OCR_PROMPT_VERSION`) и число одновременных запросов к модели (`OCR_CONCURRENCY`). Настройки роли чтения страниц MUST NOT влиять на параметры вызовов классификации, а параметры классификации MUST NOT влиять на вызовы чтения страниц. Незаданное имя модели MUST приводить к понятной ошибке конфигурации при чтении сканированного документа, а не к молчаливой пустой конвертации.

#### Scenario: Чтение страниц настроенной моделью
- **Дано** заданы `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL`
- **Когда** выполняется чтение страницы изображения
- **То** запрос отправляется модели `LLM_MODEL` по адресу `LLM_BASE_URL`

#### Scenario: Настройки роли не влияют на классификацию
- **Дано** заданы параметры роли чтения страниц, отличные от параметров классификации
- **Когда** выполняется классификация фрагмента
- **То** классификация использует параметры по умолчанию для своей роли
- **И** настройки роли чтения страниц не применяются

#### Scenario: Не задано имя модели
- **Дано** имя модели не задано и выполняется конвертация сканированного PDF
- **Когда** выполняется конвертация
- **То** возвращается понятная ошибка конфигурации

#### Scenario: Незаданное имя модели не влияет на .docx
- **Дано** имя модели не задано и выполняется конвертация файла `.docx`
- **Когда** выполняется конвертация
- **То** конвертация завершается успешно

#### Scenario: Параметры роли чтения из конфига используются при чтении
- **Дано** заданы `OCR_TIMEOUT`, `OCR_CONCURRENCY`, `OCR_PROMPT_VERSION` в конфигурации
- **Когда** выполняется чтение страниц сканированного PDF
- **То** таймаут запроса равен `OCR_TIMEOUT`
- **И** версия инструкции равна `OCR_PROMPT_VERSION`
- **И** страницы читаются с количеством одновременных запросов `OCR_CONCURRENCY`
