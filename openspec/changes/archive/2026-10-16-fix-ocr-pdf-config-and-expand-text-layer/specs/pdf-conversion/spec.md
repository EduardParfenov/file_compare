## ADDED Requirements

### Requirement: Раскрытие свёрнутого диапазона использует текстовой слой при наличии
Система SHALL при раскрытии свёрнутого диапазона страниц PDF (`read_page_range`) сначала проверять наличие текстового слоя документа. Если текстовый слой есть, текст запрашиваемых страниц MUST извлекаться детерминированно через ветку текстового слоя без обращения к модели. Если текстового слоя нет, страницы MUST читаться vision-моделью как раньше. Незаданное имя модели при отсутствии текстового слоя MUST приводить к понятной ошибке конфигурации, а не к молчаливой пустой конвертации.

#### Scenario: Раскрытие диапазона у PDF с текстовым слоем
- **Дано** PDF с текстовым слоем и свёрнутый диапазон страниц
- **Когда** пользователь запрашивает раскрытие диапазона (`POST /api/jobs/<id>/pages`)
- **То** текст страниц извлечён через ветку текстового слоя
- **И** модель для чтения страниц не вызывалась

#### Scenario: Раскрытие диапазона у скана без текстового слоя
- **Дано** сканированный PDF без текстового слоя и свёрнутый диапазон страниц
- **Когда** пользователь запрашивает раскрытие диапазона
- **То** страницы прочитаны vision-моделью
- **И** таймаут чтения равен `OCR_TIMEOUT`

#### Scenario: Раскрытие диапазона без модели и без текстового слоя
- **Дано** сканированный PDF без текстового слоя, имя модели не задано
- **Когда** пользователь запрашивает раскрытие диапазона
- **То** возвращена понятная ошибка конфигурации
