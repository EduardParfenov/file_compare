# Proposal: harden-tests

уровень: исправление

## Why

Аудит (REVIEW.md, разделы 1–2) выявил: часть требований не покрыта
тестами (потоковый `start_job`, путь `inline_diff → None`), а ряд тестов
проходят даже при неверной реализации (эхо-проверка этапов, 404 только на
несуществующих id, неполная проверка разделителя таблицы, отсутствие
теста «без лишнего ретрая»). Надёжность тестового набора нужно поднять
без изменения продуктового поведения.

## What Changes

- Тесты асинхронности (comparison-jobs): потоковый путь `start_job`
  (`JOBS_SYNCHRONOUS=False`) — задача создаётся немедленно, статус
  проходит processing → done, этапы выставляет сам пайплайн, результат
  доступен через API (корректность app-контекста в треде).
- Тест fallback пословного diff для обычных блоков (diff-viewer):
  `inline_diff → None` (порог `MAX_INLINE_TOKENS`) → изменённый блок без
  `segments`, красный/зелёный фон по панелям.
- Усиление слабых тестов:
  - `test_processing_status_with_stage_message` — без ручного
    `jobs.set_stage`, этапы выставляет пайплайн;
  - `test_unknown_upload_id_returns_404` — случай «первый id валиден,
    второй нет»;
  - `test_llm_stage_during_classification` — полная последовательность
    этапов converting → diffing → llm;
  - `test_table` (docx) — разделительная строка `| --- |` ровно одна и в
    позиции сразу после шапки; строка из одних `|` разделителем не
    считается;
  - ретраи LLM — «корректный ответ с первой попытки → ровно один вызов».
- Дешёвые недостающие тесты: заголовки уровней 3–6 и клампинг уровня
  (markdown-conversion); уникальность имени сохраняемого файла
  (file-upload); системный промпт на русском и `base_url` из
  `LLM_BASE_URL` (llm-classification).
- Каждый усиленный тест проверяется mutation-подходом (временно сломать
  код → тест падает → вернуть код).
- Спецификации не меняются (`skip_specs: true`): продуктовое поведение
  кода не затрагивается, правки только в тестах и фикстурах.

## Impact

- `tests/test_jobs.py` — потоковый тест, усиление 404/этапов.
- `tests/test_llm.py` — ретрай «ровно один вызов», промпт на русском,
  `base_url`.
- `tests/test_docx_converter.py` — разделитель таблицы, заголовки 3–6 и
  клампинг.
- `tests/test_diffing.py` — распознавание разделителя (строка из `|`).
- `tests/test_upload.py` — уникальность имён сохраняемых файлов.
- Не затрагиваются: код `app/`, спецификации, `test_deterministic`,
  UI/e2e-тесты (отдельный change).
