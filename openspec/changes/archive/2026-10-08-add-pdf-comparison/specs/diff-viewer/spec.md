## ADDED Requirements

### Requirement: Отображение номера страницы
Строка результата сравнения для PDF-документов MUST отображать номер страницы
своего источника. Для строки, в которой блоки обеих сторон совпадают по
содержимому, MUST отображаться номера страниц обеих сторон, чтобы совпавшему
блоку не была приписана чужая страница. Отображение номера страницы MUST NOT
влиять на вычисление различий и на классы изменений строк.

#### Scenario: Строка изменённого блока со страницами
- **Дано** блок на странице 4 файла 1 заменён блоком на странице 4 файла 2
- **Когда** отображается результат
- **То** обе стороны строки содержат номер страницы 4

#### Scenario: Совпадающий блок на разных страницах
- **Дано** совпадающий блок расположен на странице 5 файла 1 и на странице 5 файла 2
- **Когда** отображается результат
- **То** обе стороны строки показывают свой номер страницы

#### Scenario: Строка с номером страницы только одной стороны
- **Дано** блок присутствует только в файле 2 на странице 7
- **Когда** отображается результат
- **То** сторона файла 2 показывает номер страницы 7, противоположная сторона — пустое место без номера

### Requirement: Отображение визуально изменённых областей
Для страниц с визуальными различиями интерфейс MUST отображать изображения
изменённых областей страницы. Изображение MUST отображаться рядом с
принадлежащей ему страницей и MUST сопровождаться рамкой, обозначающей
изменённую область. Для сканированных документов, где точная привязка области
к строке недоступна, изображение MUST отображаться на уровне страницы, а
текстовые строки страницы MUST оставаться подсвеченными пословно по
текстовому различию. Наличие изображения изменённой области MUST NOT изменять
класс изменения текстовой строки и MUST NOT подменять текстовое сравнение.

#### Scenario: Изображение изменённой области у изменённой страницы
- **Дано** на странице 12 файла 2 изменён абзац и извлечён кроп этой области
- **Когда** отображается результат
- **То** у страницы 12 отображается изображение изменённой области с рамкой
- **И** строка абзаца подсвечена пословно по текстовому различию

#### Scenario: Страница без визуальных различий
- **Дано** для страницы 12 кропы не извлечены
- **Когда** отображается результат
- **То** у страницы 12 изображение изменённых областей не отображается

#### Scenario: Кропы усечены по лимиту
- **Дано** кропы страницы были частично отброшены из-за лимита объёма
- **Когда** отображается результат
- **То** отображаются только уцелевшие кропы
- **И** страница по-прежнему показывает текстовые строки с пословной подсветкой

### Requirement: Свёртывание неизменённых страниц
Непрерывный диапазон страниц, не содержащий изменений, MUST отображаться
свёрнутым в виде одной строки с указанием номера первой и последней страницы
диапазона. Свёрнутая строка MUST раскрываться по действию пользователя с
показом страниц диапазона. Если в документе отсутствуют различия и по тексту,
и по изображению, интерфейс MUST отображать сообщение о полном совпадении
вместо содержимого документа. Номера страниц в свёрнутом виде MUST
отражать нумерацию страниц своей стороны документа.

#### Scenario: Диапазон неизменённых страниц
- **Дано** страницы 3–11 двух документов признаны неизменными
- **Когда** отображается результат
- **То** вместо девяти страниц отображается одна строка «страницы 3–11 без изменений»

#### Scenario: Раскрытие диапазона
- **Дано** диапазон неизменённых страниц отображается свёрнутым
- **Когда** пользователь раскрывает диапазон
- **То** отображаются страницы диапазона с их содержимым

#### Scenario: Документы полностью совпадают
- **Дано** все страницы обоих документов признаны неизменными и текстовых различий нет
- **Когда** отображается результат
- **То** отображается сообщение о полном совпадении документов
- **И** свёрнутые диапазоны страниц не отображаются

#### Scenario: Диапазон из одной страницы
- **Дано** единственная неизменённая страница 4 не соседствует с другими неизменёнными страницами
- **Когда** отображается результат
- **То** отображается свёрнутая строка диапазона этой страницы
- **И** её раскрытие показывает содержимое страницы
