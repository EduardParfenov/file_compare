уровень: несовместимое поведение

## Why

Приложение сравнивает версии документов только в формате `.docx`. Значительная
часть сравниваемых документов существует исключительно как сканы: бумажный
документ, оцифрованный дважды (в два разных момента времени), без текстового
слоя. Такие файлы отклоняются на этапе загрузки, а весь накопленный пайплайн
(конвертация → алгоритмический diff → классификация → пословная подсветка) к
ним неприменим: сравнивать нечего, текста в файле нет.

Уже настроенная модель `qwen3-vl` умеет читать текст с изображений, поэтому
отдельный OCR-сервис не требуется: та же модель на том же эндпоинте, что уже
используется для классификации фрагментов, читает страницы скана. Это снимает
главный барьер.

## What Changes

- **BREAKING** — `.pdf` входит в поддерживаемые форматы; значение по умолчанию
  `ALLOWED_EXTENSIONS` меняется с `.docx` на `.docx,.pdf`. Конвертация PDF
  разветвляется: при наличии текстового слоя блоки извлекаются детерминированно
  без участия модели, при его отсутствии страницы читаются настроенной моделью.
- **BREAKING** — контракт блока документа расширяется необязательными полями
  `page` (номер страницы) и `crops` (изображения визуально изменённых областей
  страницы). Существующие конвертеры эти поля не эмитят.
- **BREAKING** — требование детерминированной конвертации перестаёт выполняться
  для сканированных PDF: вызов модели не воспроизводится побитово. Требование
  уточняется явным исключением и заменяется кэшированием по содержимому
  отрендеренной страницы.
- Появляется этап выравнивания по страницам на основе попиксельной разности
  отрендеренных страниц. Страницы, признанные визуально неизменными, не
  отправляются в модель вовсе; при полном совпадении документов модель не
  вызывается ни разу.
- Результат сравнения приобретает привязку строк к страницам, кропы
  визуально изменённых областей и свёрнутые диапазоны неизменённых страниц.
  Алгоритмический diff (`document-diff`) и классификация фрагментов
  (`llm-classification`) не изменяются.

Вне области действия: формат `.xlsx`; резервный детерминированный OCR
(tesseract/paddle) рядом с чтением страниц моделью; полноценный просмотрщик PDF с
наложением подсветки; точная привязка кропа к строке для сканированных
документов (требует надёжных координат слов от модели, чего у неё нет).

## Capabilities

### New Capabilities

- `pdf-conversion`: конвертация `.pdf` в блоки документа — выбор ветки по
  наличию текстового слоя, разбор markdown-вывода модели в блоки, детерминизм
  и его границы, расширение контракта блока полями `page` и `crops`.
- `vision-ocr`: чтение страниц настроенной моделью как OCR — мультимодальный
  формат запроса, параметры роли чтения, детерминированные параметры
  генерации, кэш по странице, деградация при недоступности модели.
- `page-image-diff`: попиксельное сравнение отрендеренных страниц —
  параметры рендера, порог консервативной маски, выравнивание страниц двух
  документов, извлечение и ограничение кропов изменённых областей.

### Modified Capabilities

- `file-upload`: поддержка формата `.pdf` и достаточный лимит размера загрузки
  для многостраничных сканов.
- `comparison-jobs`: результат задачи дополняется выравниванием страниц,
  свёрнутыми диапазонами и кропами; конвертация получает доступ к модели
  через внедрение, а задача — прогресс по страницам.
- `diff-viewer`: отображение номера страницы, кропов визуально изменённых
  областей и свёрнутых диапазонов неизменённых страниц.

`markdown-conversion` и `document-diff` не изменяются: реестр конвертеров уже
формато-независим, а алгоритм diff работает с последовательностью блоков и не
знает о страницах.

## Impact

- **Код**: `app/services/conversion.py` (регистрация `.pdf`),
  новые `pdf_converter.py`, `vision_ocr.py`, `page_image_diff.py`;
  `app/services/llm.py` (фабрика клиента с явными параметрами вызова),
  `app/services/jobs.py` (выравнивание страниц, кропы, свёртывание),
  `app/routes.py` (сборка модели), `app/__init__.py` (настройки роли чтения),
  `app/static/app.js`, `app/templates/index.html`, `app/static/style.css`
  (бейдж страницы, кропы, свёрнутые диапазоны).
- **Зависимости**: `pypdfium2` (рендер страниц) и `pdfplumber` (текстовый слой и
  координаты слов) — только pip, без системных пакетов.
- **Конфигурация**: новые настройки роли чтения страниц (таймаут, число
  одновременных запросов, версия инструкции), а также `PDF_RENDER_DPI` и лимит
  кропов на документ. Имя модели, адрес и ключ API остаются общими с
  классификацией фрагментов — отдельной конфигурации модели не появляется.
  В `.env.example` боевой внутренний адрес LLM заменяется плейсхолдером,
  `MAX_CONTENT_LENGTH` повышается, в `ALLOWED_EXTENSIONS` добавляется `.pdf`.
- **API**: `GET /api/jobs/<job_id>` дополняется необязательным прогрессом
  конвертации; результат задачи дополняется полями выравнивания страниц.
- **Тесты**: модель мокается, сеть не используется; требуются
  фикстуры — синтетический родной PDF и синтетический скан.
- **Версия**: при архивации — major, `VERSION` 1.0.4 → 2.0.0.
