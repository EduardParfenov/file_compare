# Предложение: корректная конвертация объединённых ячеек (flatten)

> Оформлено задним числом: реализация уже выполнена,
> основная спека `markdown-conversion` синхронизирована.

## Why

Таблицы с объединёнными ячейками отображались в diff viewer с дефектами:

1. `cell.text` объединённой ячейки содержит переносы строк (`\n`) —
   Markdown-строка таблицы разрывалась на несколько строк, таблица
   «разваливалась» в блоках и на экране.
2. python-docx повторяет объединённую ячейку в `row.cells` (один и тот же
   `tc`): при горизонтальном merge текст дублировался в соседних
   «виртуальных» ячейках, при вертикальном — в строках-продолжениях
   (Word показывает такой текст один раз).

## What Changes

- Переносы и множественные пробелы внутри ячейки сворачиваются в один
  пробел — строка таблицы всегда однострочная.
- Дедупликация merge-ячеек по элементу `tc` (flatten): текст объединённой
  ячейки эмитируется один раз в первой позиции, повторные виртуальные
  ячейки — пустыми. Число колонок в строках таблицы сохраняется,
  выравнивание diff не ломается, формат API результата не меняется.
- Полноценные colspan/rowspan (точный вид как в Word) — возможный
  следующий этап, вне рамок этого change.
