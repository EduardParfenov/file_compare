## Логика приложения — приоритет над инфраструктурой (решено 2026-10-09)

- [ ] Границы жизни состояния: `jobs._JOBS` (результат с data-URI
      хранится в RAM неограниченно), `vision_ocr._CACHE` (кэш страниц
      без вытеснения) и файлы `uploads/` (сейчас 215 файлов, 192 МБ)
      растут бесконечно. Решено: результат не переживает закрытие
      вкладки; файлы удаляются по TTL, чистка — по mtime каталога
      (после рестарта процесса файлы не находит никто, чистка по
      реестру их не видит).
- [ ] Раскрытие свёрнутого диапазона у PDF с текстовым слоем идёт через
      vision-модель: `read_page_range` не проверяет `has_text_layer`
      (`conversion.py:162`) — платный вызов за текст, лежащий в файле,
      недетерминированный результат против детерминированного
      сравнения, 409 при недоступной модели.
